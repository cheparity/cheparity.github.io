    DDPM

    Perturbation Process

    加噪 Perturbation，是从原图 x0x_{0}x0​ 逐步加噪到高斯噪声 xTx_{T}xT​：

    xt=βtϵ+1−βtxt−1(1)x_{t}=\sqrt{ \beta_{t} } \epsilon+\sqrt{ 1-\beta_{t} } x_{t-1} \tag{1}xt​=βt​​ϵ+1−βt​​xt−1​(1)

    βt\beta_{t}βt​ 随时间 ttt 增长，betas = np.linearspace(0.0001, 0.02, 1000) 也就是从 min=0.0001 到 max=0.02 均匀生成 1000 个 tensor，导致加的噪声越来越大，均值缩放程度越来越小。 αt=1−βt\alpha_{t}=1-\beta_{t}αt​=1−βt​。alphas = 1.0 - betas

    加的噪声 noise = torch.randn_like(x) 与 xxx 的形状保持一致。

    图像像素 xxx 是原图 [0,255] 经过映射到 [-1,1] 再加噪的。映射公式是：x:=x255∗2−1x:=\frac{x}{255}*2-1x:=255x​∗2−1。torchvision.transforms.ToTensor() 可以做到把图像从 [0,255] 转化为 [0,1] 的张量。

    我们可以从 x0x_{0}x0​ 直接生成任意时间的图像 xtx_{t}xt​:

    xt=1−αtˉϵ+αtˉx0(2)x_{t}=\sqrt{ 1-\bar{\alpha_{t}} }\epsilon + \sqrt{ \bar{\alpha_{t}} } x_{0} \tag{2} xt​=1−αt​ˉ​​ϵ+αt​ˉ​​x0​(2)

    我们训练的核心就是在加噪过程，基本 idea 就是用网络预测一个 ϵθ\epsilon_{\theta}ϵθ​ 去逼近加噪过程的噪声 ϵ\epsilonϵ。

    Denoise Process

    这个和采样过程关系比较大。

    去噪过程相反。从一张高斯分布的图片 xTx_{T}xT​ 到高清原图 x0x_{0}x0​，完成生成过程。

    DDPM 不是去直接预测原图，而是预测一个可以去除的噪声 ϵθ\epsilon_{\theta}ϵθ​，通过以下公式：

    xt−1=1αt(xt−1−αt1−αtˉϵθ)+σtz(3)x_{t-1}=\frac{1}{\sqrt{ \alpha_{t} }}\left( x_{t}-\frac{1-\alpha_{t}}{\sqrt{ 1-\bar{\alpha_{t}} }}\epsilon_{\theta} \right)+\sigma_{t}z \tag{3}xt−1​=αt​​1​(xt​−1−αt​ˉ​​1−αt​​ϵθ​)+σt​z(3)

    关键的就是这个可去除噪声 ϵθ\epsilon_{\theta}ϵθ​，由神经网络预测。输入是 ttt 时刻的图像 xtx_{t}xt​ 和编码的时间 ttt 信息，经过 UNet 网络预测。z∈N(0,1)z \in N(0,1)z∈N(0,1)

    这个式子在苏剑林的博客 生成扩散模型漫谈（一）：DDPM = 拆楼 + 建楼 - 科学空间|Scientific Spaces生成扩散模型漫谈（一）：DDPM = 拆楼 + 建楼 - 科学空间|Scientific Spacesspaces.ac.cn 里推导得比较好。他注意到公式 (1) 可以用

    xt−1=1αtxt−βtϵ(4)x_{t-1}=\frac{1}{\sqrt{ \alpha_{t} }}x_{t}-\sqrt{ \beta_{t} }\epsilon \tag 4xt−1​=αt​​1​xt​−βt​​ϵ(4)

    表示，所以先假设了去噪过程 xtx_{t}xt​ 和 ϵ\epsilonϵ 之前的系数，然后解方程推出来的。

    Training

    与加噪过程紧密相关，基本 idea 就是用 UNet 网络预测一个 ϵθ\epsilon_{\theta}ϵθ​ 去逼近每一个加噪过程的噪声 ϵ\epsilonϵ。

    1. x0∼q(x0)x_{0} \sim q(x_{0})x0​∼q(x0​)，意思是从数据集中采样一张原图 x0x_{0}x0​
    2. t∼Uniform({1,…T})t \sim \text{Uniform}(\{1,\dots T\})t∼Uniform({1,…T})，Uniform 是均匀分布，意思是选定一个时间步 ttt
    3. ϵ∼N(0,1)\epsilon \sim N(0,1)ϵ∼N(0,1)，从高斯分布中采样出该时间步 ttt 加的噪声。这个 ϵ\epsilonϵ 是 Ground Truth
    4. 预测该步加噪后的图片 x_{t}=\sqrt{ 1-\bar{\alpha_{t}} }\epsilon + \sqrt{ \bar{\alpha_{t}} } x_{0} \tag{2}。αt\alpha_{t}αt​ 是之前通过假设 βt\beta_{t}βt​ 得出的常数
    5. 用 UNet 预测噪声。输入 encoded ttt 和在第 4 步获得的 ttt 时刻的图像 xtx_{t}xt​，预测一个噪声 ϵθ(xt,t)=ϵθ(1−αtˉϵ+αtˉx0,t)\epsilon_{\theta}(x_{t}, t)=\epsilon_{\theta}(\sqrt{ 1-\bar{\alpha_{t}} }\epsilon + \sqrt{ \bar{\alpha_{t}} } x_{0},t)ϵθ​(xt​,t)=ϵθ​(1−αt​ˉ​​ϵ+αt​ˉ​​x0​,t)。这个 ϵθ\epsilon_{\theta}ϵθ​ 是模型预测值，需要逼近 Ground Truth
    6. 计算梯度 ∇θ∣∣ϵ−ϵθ(1−αtˉϵ+αtˉx0)∣∣22\nabla_{\theta}|| \epsilon - \epsilon_{\theta}(\sqrt{ 1-\bar{\alpha_{t}} }\epsilon + \sqrt{ \bar{\alpha_{t}} } x_{0}) ||_{2}^2∇θ​∣∣ϵ−ϵθ​(1−αt​ˉ​​ϵ+αt​ˉ​​x0​)∣∣22​ 重复以上过程直至收敛

    其实核心思想就在于，我们通过公式可以直接从原图 x0x_{0}x0​ 加一个高斯噪声 ϵ\epsilonϵ，到 xtx_{t}xt​，然后我们只需要得知第 ttt 步加噪多少就可以了——这一部分直接交给神经网络去拟合。如果我们能预测出第 t 步加的噪声，那么我们就能一步一步反向去噪得到原图。这就是采样过程。

    最后这个损失函数推导还挺难的。但是很符合直觉。

    Sampling

    说是采样，其实就是推理过程。基本 idea 是我们已经有可以推理出每一个时间 t 下，加了多少噪声的模型 ϵθ(xt,t)\epsilon_{\theta}(x_{t},t)ϵθ​(xt​,t) 了，那我们用公式 (3) 反向推回去就行。

    1. xt=N(0,1)x_{t}=N(0,1)xt​=N(0,1)。这是推理的起点。在加噪之后获得一张纯高斯噪声图片 xtx_{t}xt​。
    2. for t = T, …, 1 循环以下过程
      1. 先采样 z∼N(0,1) for t>1 , else z=0z \sim N(0,1) \text{ for t>1 , else }z=0z∼N(0,1) for t>1 , else z=0。这个是公式 (3) 里反向去噪用到的高斯 perturbation
      2. xt−1=1αt(xt−1−αt1−αtˉϵθ(xt,t))+σtzx_{t-1}=\frac{1}{\sqrt{ \alpha_{t} }}\left( x_{t}-\frac{1-\alpha_{t}}{\sqrt{ 1-\bar{\alpha_{t}} }}\epsilon_{\theta}(x_{t},t) \right)+\sigma_{t}zxt−1​=αt​​1​(xt​−1−αt​ˉ​​1−αt​​ϵθ​(xt​,t))+σt​z，利用公式 (3) 递推去噪的图片
    3. 返回去噪的图片 x0x_{0}x0​

    再次提醒我们的 UNet 网络预测的是噪声，输入是图像 xtx_{t}xt​ 以及编码的时间信息 ttt，输出是 ϵθ(xt,t)\epsilon_{\theta}(x_{t},t)ϵθ​(xt​,t)
