    霍夫丁不等式 (Hoeffding’s inequality)

    设有两两独立的随机变量 X1,…,Xn ⁣X_1, \dots, X_n \!X1​,…,Xn​，那么它们的经验期望值（含义见后）：

    X‾=X1+⋯+Xnn\overline{X} = \frac{X_1 + \cdots + X_n}{n} X=nX1​+⋯+Xn​​

    满足：

    P(X‾−E[X‾]≥t)≤exp⁡(−2t2n2∑i=1n(bi−ai)2), ⁣\mathbb{P}(\overline{X} - \mathbb{E}[\overline{X}] \geq t) \leq \exp \left( - \frac{2t^2n^2}{\sum_{i=1}^n (b_i - a_i)^2} \right),\!P(X−E[X]≥t)≤exp(−∑i=1n​(bi​−ai​)22t2n2​),

    经验期望 (Empirical Expectation)

    经验期望是根据有限的观测数据来估计总体期望。假设我们有一组数据 x1,x2,…,xnx_1,x_2,…,x_nx1​,x2​,…,xn​，这些数据是来自一个随机变量 XXX 的独立同分布 (i.i.d.) 样本。那么，经验期望（或者说样本均值）的定义为：

    E^[X]=1n∑i=1nxi\mathbb{\hat{E}}[X]=\frac{1}{n}\sum_{i=1}^{n}x_iE^[X]=n1​i=1∑n​xi​

    这个公式表示将所有样本值加起来后除以样本个数，得到的结果就是经验期望，它是对总体期望 E(X)\mathbb{E}(X)E(X) 的一个估计。﻿

    多臂赌博机中的上置信界

    这是在读 《动手学深度学习》《动手学深度学习》hrl.boyuai.com 的上置信界算法（upper confidence bound，UCB）时产生的思考。UCB 是怎么取的呢？假设当某一个臂被摇了 n 次（在动作 Action aaa）之后，产生的累计效益 Q^(a)\hat{Q}(a)Q^​(a) 依然很低时，我们值不值得再去摇它呢？

    霍夫丁不等式可以说明这个问题。经验期望是在有限次观察下，该臂所产生的效益 Q^(a)\hat{Q}(a)Q^​(a)。注意，我们的 Q^(a)=1n∑i=1nri\hat{Q}(a) =\frac{1}{n}\sum_{i=1}^{n}r_iQ^​(a)=n1​∑i=1n​ri​，其中 r 指 reward。在观察次数足够多（long term）的时候，Q^(a)\hat{Q}(a)Q^​(a) 应该会趋近于其期望 E[Q(a)]\mathbb{E}[Q(a)]E[Q(a)]。注意，经验期望是不稳定，不一定可信的，而期望指长期观察结果，是赌博机的固有属性，稳定又可信。

    那么，Q^(a)\hat{Q}(a)Q^​(a) 与其期望的“偏差”就是上文霍夫丁不等式中的 ttt。“偏差”越大，就越“值得”探索。这个“偏差”就是不确定性度量 uncertainty U(a)U(a)U(a)。

    进而，如果我们令不等式右边 exp 那一坨为概率 ppp，可以得知 （以下简称某一臂摇动获得的效益 Q^(a)\hat{Q}(a)Q^​(a) 为“经验效益”，效益的期望为“真实期望”，不确定性度量 uncertainty 为 uuu）：

    1. 真实期望比经验效益还多 uuu，这件事的概率至多为 ppp；
    2. 真实期望不超过我们观测到的经验效益 +uuu，这件事的概率至少为 1−p1-p1−p；
    3. 随着次数 nnn 越来越多，ppp 也在越来越小，所以（2）变得越来越可信，即：真实期望有一个上限值，这个上限值就是我们观测到的经验效益 + 不确定性度量 uuu。
    4. 上置信界算法便选取期望奖励上界最大的动作。注意这个“期望奖励上界”肯定指真实期望，我们毕竟是要估算赌博机的固有属性，长期期望的。
    5. 我们每次选择的是，期望奖励上界最大的摇臂。

    接下来就是不太明白为什么 UCB 算法比 ϵ\epsilonϵ-gready 算法的累计懊悔还多了。
