    MDH (Modified Denavit-Hartenberg) 参数

    机械臂逆运动学 (Inverse Kinematics, IK)

    为了实现对机器人的任务规划和控制（“我要到那里，关节应该怎么动？”），逆运动学输入末端执行器的位姿矩阵 T\mathbf{T}T，输出所有关节变量 θi\theta_iθi​ 或 did_idi​。

    这个问题的解非唯一确定。如图，我们已知了 (x,y)(x,y)(x,y)，若要求出两个关节的参数，那么会有至少两组解，即图中的实线和虚线。通常需要根据实际约束（如关节限制、避障、最快/最节能等）来选择最优解。

    求解问题：

    • Reachable workspace: 可达空间
    • Dexterous workspace: 手臂可以以任意姿态到达的空间

    求解方法

    IK 求解主要分为两类：

    解析法（Analytic Solutions）

    适用于具有特定几何特征（如球形手腕）的机器人，能够得到精确的闭式解 (Closed-form solution)。能由闭式解的话求解速度很快，因此目前大多机械手臂都设计成具有解析解。

    • 解耦： 通过将机器人分解为手臂（位置）和手腕（姿态）两部分来简化问题。
      • 手臂位置：通常利用几何法或代数法求解前三个关节角。
      • 手腕姿态：对于具有球形手腕（三个关节轴线交于一点）的机器人，可以通过逆变换或欧拉角分解独立求解后三个关节角。
    • 几何法：直接利用几何关系（如余弦定理）求解角度。
    • 代数法：通过将 TN0\mathbf{T}_N^0TN0​ 矩阵的元素与 FK 连乘展开后的三角函数表达式进行匹配和求解。

    代数法主要通过左乘连杆变换矩阵的逆，逐步分离关节变量：

    10T−1⋅N0T=21T⋯NN−1T{}_1^0\mathbf{T}^{-1} \cdot {}_N^0\mathbf{T} = {}_2^1\mathbf{T} \cdots {}_N^{N-1}\mathbf{T}10​T−1⋅N0​T=21​T⋯NN−1​T

    几何法通过余弦定理求解关节角。感觉是个纯平面几何的问题，就不多说了。

    数值法（Numerical Solutions）

    Hint

    感觉这一块儿理论和数学的内容很多。实际上要掌握调库应该就可以

    适用于几何结构复杂、无法得到解析解的机器人，通过迭代逼近来寻找近似解。

    • 基础：基于迭代优化，通常需要机器人雅可比矩阵 J\mathbf{J}J。
    • 过程：通过计算末端位姿误差 ΔX\Delta \mathbf{X}ΔX，并利用 ΔX=JΔΘ\Delta \mathbf{X} = \mathbf{J} \Delta \mathbf{\Theta}ΔX=JΔΘ 来迭代更新关节角 Θ\mathbf{\Theta}Θ，直到误差足够小。
    • 雅可比矩阵 J\mathbf{J}J：描述关节速度与末端执行器线速度和角速度之间的关系，是 IK 数值解法的核心。
    • 缺点：初始猜测值敏感、收敛速度慢、可能陷入局部最优解、计算量大。

    微分运动学关系：末端执行器的广义速度 X˙\dot{\mathbf{X}}X˙ 与关节速度 Θ˙\dot{\mathbf{\Theta}}Θ˙ 的关系：

    X˙=J(Θ)Θ˙\dot{\mathbf{X}} = \mathbf{J}(\mathbf{\Theta}) \dot{\mathbf{\Theta}}X˙=J(Θ)Θ˙

    IK 数值迭代，利用雅可比矩阵的伪逆 J+\mathbf{J}^{+}J+ 来求解关节修正量 ΔΘk\Delta\mathbf{\Theta}_kΔΘk​

    Θk+1=Θk+ΔΘk其中ΔΘk=J(Θk)+ΔXk\mathbf{\Theta}_{k+1} = \mathbf{\Theta}_k + \Delta\mathbf{\Theta}_k \quad \text{其中} \quad \Delta\mathbf{\Theta}_k = \mathbf{J}(\mathbf{\Theta}_k)^{+} \Delta\mathbf{X}_kΘk+1​=Θk​+ΔΘk​其中ΔΘk​=J(Θk​)+ΔXk​

    雅可比伪逆 (Moore-Penrose Pseudoinverse)。当 J\mathbf{J}J 是 m×nm \times nm×n 矩阵时：

    J+=JT(JJT)−1(当 n<m 时，左伪逆)J+=(JTJ)−1JT(当 n>m 时，右伪逆)\mathbf{J}^{+} = \mathbf{J}^T (\mathbf{J} \mathbf{J}^T)^{-1} \quad (\text{当 } n < m \text{ 时，左伪逆}) \mathbf{J}^{+} = (\mathbf{J}^T \mathbf{J})^{-1} \mathbf{J}^T \quad (\text{当 } n > m \text{ 时，右伪逆})J+=JT(JJT)−1(当 n<m 时，左伪逆)J+=(JTJ)−1JT(当 n>m 时，右伪逆)

    误差由相对变换矩阵 Terror\mathbf{T}_{\text{error}}Terror​ 提取（包含位置误差 Δp\Delta\mathbf{p}Δp 和姿态误差 Δϕ\Delta\boldsymbol{\phi}Δϕ）
