    Tips

    1. d = { } 初始化是 dict，而不是 set。但是为了可读性，建议直接用 dict()
    2. 如果一个 key not in dict，会直接抛出 KeyError，所以要用 if key not in dict 检查。collections.defaultdict() 是 dict() 子类，第一个参数为 default_factory 提供一个初始值，默认为 None，改成 int 或者 list 这种可以避免异常。
    3. 字典的 key 只能是可变长度的，因此 tuple 可以当 key，而 list 不行。
    4. ord() 传入字母，输出 ASKII 码。逆运算是 chr()：
      • ord('a') →\rightarrow→ 97
      • chr(97) →\rightarrow→ 'a'
