    平稳分布、详细平衡条件

    那么先哲们是如何通过马尔科夫链，去跟采样这件事情联想起来的呢？

    其实马尔可夫链本身就可以看作是对概率分布 PPP 的建模。举个很简单的例子，我们要对北京 A、上海 B三个地方的人口密度分布进行建模。当前的概率分布为 π(A)=0.6,π(B)=0.4\pi(A)=0.6, \pi(B)=0.4π(A)=0.6,π(B)=0.4，并假设人口在城市间的转移概率服从马尔可夫链：

    当前城市 → 下一个城市AB
    A0.70.3
    B0.50.5

    那我们想问：下一步 A 点的分布是什么？

    好算！π(A)=π(A)⋅P(A→A)+π(B)⋅P(B→A)=0.6⋅0.7+0.4⋅0.5=0.42+0.2=0.62π(A)=π(A)⋅P(A→A)+π(B)⋅P(B→A)=0.6⋅0.7+0.4⋅0.5=0.42+0.2=0.62π(A)=π(A)⋅P(A→A)+π(B)⋅P(B→A)=0.6⋅0.7+0.4⋅0.5=0.42+0.2=0.62

    原先的分布里 A 的概率是 0.6，现在变成了 0.62，依然不平稳。但根据遍历定理，再过几步，A 和 B 的概率分布一定可以达到平稳状态。

    从上面的例子中我们提出几个符号：

    • π(x)\pi(x)π(x)：表示当前在状态 x 的概率（这是你当前的分布）
    • P(x→x′)P(x \to x')P(x→x′)：从状态 x 跳到状态 x′ 的转移概率

    所以 π(x)P(x→x′)\pi(x) P(x \to x')π(x)P(x→x′)：表示你现在在 x，然后走到 x′的整体概率流量。遍历所有能走到 x′x'x′ 的路，就是 Σπ(x)P(x→x′),∀x\Sigma \pi(x)P(x \to x') ,\forall xΣπ(x)P(x→x′),∀x ，这个式子表示下一个时间步里 x′x'x′ 的分布情况，如果能够与 π(x′)\pi(x')π(x′)——也就是当前 x’的分布相等，那么说明什么？

    说明“再走一步，分布不变”，说明我们达到了平稳分布！

    而详细平衡条件是一个更强的条件，能推出平稳分布。如果我们有从北京到上海的人流，与从上海到北京到人流相等，——也就是任意两个点之间双向的流量相等，——那么就说明系统达到平稳分布了。

    π(x)P(x→x′)=π(x′)P(x′→x)\pi(x)P(x \to x')=\pi(x')P(x'\to x)π(x)P(x→x′)=π(x′)P(x′→x)

    以上就是详细平衡条件。

    从前面那个公式：

    π(x′)=∑xπ(x)P(x→x′)π(x′)=∑xπ(x)P(x→x′)π(x')=∑_xπ(x)P(x→x')\pi(x') = \sum_{x} \pi(x) P(x \to x')π(x′)=∑x​π(x)P(x→x′)π(x′)=∑x​π(x)P(x→x′)

    如果每一对 (x,x′)(x, x')(x,x′) 都满足 π(x)P(x→x′)=π(x′)P(x′→x)\pi(x) P(x \to x') = \pi(x') P(x' \to x)π(x)P(x→x′)=π(x′)P(x′→x)

    那么就可以替换右边成：

    ∑xπ(x′)P(x′→x)=π(x′)∑xP(x′→x)=π(x′)\sum_{x} \pi(x') P(x' \to x) = \pi(x') \sum_{x} P(x' \to x) = \pi(x')∑x​π(x′)P(x′→x)=π(x′)∑x​P(x′→x)=π(x′)（因为对马尔科夫链来说，∑xP(x′→x)=1\sum_{x} P(x' \to x) = 1∑x​P(x′→x)=1）

    所以，详细平衡 ⇒ 平稳分布。

    M-H MCMC

    MH 的厉害之处就是：

    通过一个简单的“接受 - 拒绝”机制，构造出满足详细平衡的马尔科夫链，从而让我们能从目标分布 π(x)\pi(x)π(x) 采样。

    基本概念有：

    1. 🎯目标分布 π(x)\pi(x)π(x)。我们的目标分布 π(x){\pi(x)}π(x) 可以是一个很复杂的分布，不需要知道归一化常数 ZZZ。
    2. ❔提议分布 q(x′∣x)q(x'|x)q(x′∣x)。表示当前状态 x 下，打算怎么样跳到 x’。
    3. 有了提议分布，我们却并不打算接受它。我们以概率 α=min(1,π(x′)q(x∣x′)π(x)q(x′∣x))\alpha=min(1, \frac{\pi(x')q(x|x')}{\pi(x)q(x'|x)})α=min(1,π(x)q(x′∣x)π(x′)q(x∣x′)​) 的概率接受它。

    很懵，我来告诉你为什么这么做。

    现在我们的转移概率变成了 P(x→x′)=q(x′∣x)αP(x \to x')=q(x'|x)\alphaP(x→x′)=q(x′∣x)α，乘上当前的状态 π(x)\pi(x)π(x) 就是下一个时刻从 x 到 x’的“流量”：

    π(x)P(x→x′)=π(x)q(x′∣x)α(x,x′)=min(π(x)q(x′∣x),π(x′)q(x∣x′))π(x)P(x→x')=π(x)q(x'∣x)α(x,x')=min(π(x)q(x'∣x),π(x')q(x∣x'))π(x)P(x→x′)=π(x)q(x′∣x)α(x,x′)=min(π(x)q(x′∣x),π(x′)q(x∣x′))

    观察到这个式子是对称的！也就是说下一个时刻从 x’到 x 的“流量”，依然等于右式。想想之前“详细平稳”的条件——任意两个点之间双向的流量相等，我们成功证明了按照 M-H 方法，系统达到了详细平衡，也达到了平稳分布。

    Langevin MCMC

    人工智能专业的学生表示 Langevin 方程懂不了一点。我直接复制 GPT 了：

    朗之万动力学（Langevin Dynamics）采样是非常有趣且强大的采样方法，尤其适合于连续分布和物理模拟。我们可以将它视为一种基于物理系统的马尔科夫链蒙特卡洛（MCMC）方法，它使用了梯度信息来引导采样，从而能够更加高效地在复杂分布中采样。

    🧠 朗之万动力学采样的基本思路

    朗之万动力学采样（Langevin sampling）是通过模拟物理系统中的粒子运动来获得目标分布的样本。这个过程受到以下两方面的影响：

    1. 势能（Potential energy）：它是目标分布的对数值，用来定义粒子的行为。
    2. 噪声：模拟粒子的随机运动，用来引入随机性。

    这类似于温度控制的物理过程，其中粒子在潜在势场中受力，并且每次迭代都受到随机扰动。

    🔬 朗之万方程（Langevin Equation）

    在经典物理中，朗之万方程描述了粒子如何在势能场中运动。其数学表达式如下：

    dxdt=−∇U(x)+2γ η(t)\frac{dx}{dt} = - \nabla U(x) + \sqrt{2 \gamma} \, \eta(t)dtdx​=−∇U(x)+2γ​η(t)

    其中：

    • x 是粒子的状态（类似于 MCMC 中的采样点），
    • U(x) 是势能（在采样中，它通常是目标分布的负对数），
    • γ 是摩擦系数（决定粒子运动的阻力），
    • η(t) 是一个高斯白噪声，代表随机扰动。

    🧑‍🔬 离散化的朗之万动力学采样

    由于朗之万方程是连续的，我们通常需要将其离散化以便在计算机上实现。在离散化时，我们使用欧拉方法：

    xt+1=xt−ϵ∇U(xt)+2ϵγ ξxt+1=xt−ϵ∇U(xt)+2ϵγ ξtx_{t+1}=x_t−ϵ∇U(x_t)+2ϵγ ξx_{t+1} = x_t - \epsilon \nabla U(x_t) + \sqrt{2 \epsilon \gamma} \, \xi_txt+1​=xt​−ϵ∇U(xt​)+2ϵγ ξxt+1​=xt​−ϵ∇U(xt​)+2ϵγ​ξt​

    其中：

    • ϵ\epsilonϵ 是步长（控制每一步的更新幅度），
    • ∇U(xt)\nabla U(x_t)∇U(xt​) 是目标分布（势能）的梯度，似乎只有这个是比较重要的
    • ξt\xi_tξt​ 是标准正态分布的随机噪声（每一步的随机扰动）。

    在 Energy-based model 的语境下：

    p(x)=e−U(x)Zp(x)=\frac{e^{-U(x)}}{Z}p(x)=Ze−U(x)​

    能量

    U(x)=−log⁡p(x)U(x)=-\log p(x)U(x)=−logp(x)

    我们已知条件是 score-function

    sθ(x)≈∇xlog⁡p(x)s_\theta(x) \approx \nabla_x \log p(x)sθ​(x)≈∇x​logp(x)

    因此在 Langevin MCMC 中

    ∇xU(xt)=−∇xlog⁡p(x)\nabla_x U(x_t)=-\nabla_x \log p(x)∇x​U(xt​)=−∇x​logp(x)

    对应了“概率往梯度上升的方向走”。

    🎯 步骤概述：朗之万采样算法

    1. 初始化：选择一个起始点 x0x_0x0​。
    2. 计算梯度：计算目标分布的梯度 ∇U(xt)\nabla U(x_t)∇U(xt​)。
    3. 更新状态：根据离散化的朗之万方程更新状态 xt+1x_{t+1}xt+1​。
    4. 重复：重复多次，直到收集足够的样本。

    🎯 优点与应用

    • 高效采样：朗之万采样可以高效地在复杂的目标分布中采样，尤其适用于有梯度信息的情形。
    • 物理模型模拟：广泛应用于分子动力学模拟、粒子系统、统计物理等领域。
    • 与 MH 对比：相较于 Metropolis-Hastings，朗之万采样通过使用梯度信息，可以在某些情况下更快收敛，并且更好地探索复杂的多峰分布。
